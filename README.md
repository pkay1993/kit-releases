# kit-releases

Signierte Release-Pakete fuer das Smart-Home-Kit. Hier liegen nur fertige Pakete
(LATEST, kit-X.Y.Z.tar.gz, .sha256, .sig, .notes.txt). Das Kit fragt hier nur nach
Updates, wenn der Nutzer das im Einrichtungs-Assistenten ausdruecklich eingeschaltet hat,
und uebernimmt ein Paket nur bei gueltiger Signatur.
